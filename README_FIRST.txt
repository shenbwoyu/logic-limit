LOGIC LIMIT v5.6.1 - Windows project

FIRST TIME IN THIS FOLDER
1. Double-click SETUP_ONCE.cmd.
2. Wait until it says SETUP COMPLETE.
3. Double-click PLAY_TEST.cmd to test the game.
4. Double-click BUILD_WINDOWS.cmd to create the EXE files.

LATER UPDATES
- Do not run setup again.
- Replace app\index.html with the updated game file.
- Double-click BUILD_WINDOWS.cmd.

ONE-FILE OPTION
- QUICK_START.cmd automatically runs setup only when packages are missing,
  then builds the game.

OUTPUT
- dist\LOGIC_LIMIT_Portable_5.6.1_x64.exe
- dist\LOGIC_LIMIT_Setup_5.6.1_x64.exe

SHORTCUTS IN THE GAME
- F11 or Alt+Enter: fullscreen
- Esc: pause menu (save, restart, home, continue)
- Ctrl+S: save
- R: restart current case
